Abstract

In traditional AR games, users interact with virtual objects via flat touch screens, which breaks immersion and restricts interactions to 2D planes. This project presents a touch-free spatial interaction framework by bridging Google MediaPipe's Hand Landmarker model directly with Unity's AR Foundation.

By bypassing the camera hardware lock, marshaling multi-threaded native C++ callbacks, and using perspective geometry to estimate depth dynamically, our bridge solution establishes a reliable interface for mapping physical hand movements directly to Unity's 3D physics engine. Players can press virtual floating buttons, shield themselves from threats, and launch rockets at targets using raw hand coordinates.

The AR-MediaPipe Bridge Solution

Building touch-free interactions requires overcoming camera lock conflicts (ARCore/ARKit own the camera) and thread limitations. Here are the core modules that bridge the gap:

To avoid camera device lock conflicts, ARRawCameraSource.cs taps into the AR Foundation pipeline. It retrieves raw CPU images, converts them to RGBA32 format with a MirrorY transform, and updates a dynamic Texture2D passed to the tracking model. 

private unsafe void OnCameraFrameReceived(ARCameraFrameEventArgs eventArgs)
{
    if (!arCameraManager.TryAcquireLatestCpuImage(out XRCpuImage image)) return;

    var conversionParams = new XRCpuImage.ConversionParams {
        inputRect = new RectInt(0, 0, image.width, image.height),
        outputDimensions = new Vector2Int(image.width, image.height),
        outputFormat = TextureFormat.RGBA32,
        transformation = XRCpuImage.Transformation.MirrorY
    };

    if (_outputTexture == null || _outputTexture.width != image.width) {
        _outputTexture = new Texture2D(image.width, image.height, TextureFormat.RGBA32, false);
    }

    int size = image.GetConvertedDataSize(conversionParams);
    var buffer = new NativeArray<byte>(size, Allocator.Temp);
    image.Convert(conversionParams, new IntPtr(buffer.GetUnsafePtr()), buffer.Length);
    _outputTexture.LoadRawTextureData(buffer);
    _outputTexture.Apply();

    image.Dispose();
    buffer.Dispose();
}

MediaPipe runs inference asynchronous to Unity's game loop on a background thread. The thread-safe MainThreadDispatcher enqueues actions from the background thread and invokes them during the main Update() loop to safely execute Unity API operations. 

public class MainThreadDispatcher : MonoBehaviour
{
    private static readonly Queue<Action> _executionQueue = new Queue<Action>();

    public void Enqueue(Action action)
    {
        lock (_executionQueue) {
            _executionQueue.Enqueue(action);
        }
    }

    void Update()
    {
        lock (_executionQueue) {
            while (_executionQueue.Count > 0) {
                _executionQueue.Dequeue().Invoke();
            }
        }
    }
}

To recover depth from a single 2D viewport perspective, we measure the relative size of the hand. We compute the 2D Euclidean distance ($apparentSize$) between the Wrist (Joint 0) and the Middle MCP (Joint 9). Z-depth is calculated using the formula: $z = \frac{Multiplier}{apparentSize}$, mapping it into 3D world space. 

// Apparent size of the hand in 2D viewport
float apparentSize = Vector2.Distance(new Vector2(wrist.x, wrist.y), new Vector2(middleMcp.x, middleMcp.y));
if (apparentSize < 0.001f) apparentSize = 0.001f;

// Calculate distance via perspective scaling
float estimatedDepth = depthMultiplier / apparentSize;
estimatedDepth = Mathf.Clamp(estimatedDepth, minDepth, maxDepth);

// Translate viewport coordinates to 3D world space
Vector3 worldPos = mainARCamera.ViewportToWorldPoint(new Vector3(1f - indexTip.x, 1f - indexTip.y, estimatedDepth));

Physics Hand Interactions

  • Dynamic Hand Visualizer: Reconstructs hand geometry dynamically in 3D using coordinate mapping and custom point joints.
  • Collision Proxy: Connects a sphere collider rigid body to the index finger tip to translate gestures into physics triggers.
  • Interactive Triggers: In-world shoot and shield button prefabs with built-in cooldowns and audio feedback.

Entity & Anchor Mechanics

  • AR World Stabilization: Implements ARAnchor on Golem targets to lock virtual enemies onto flat planes, preventing drift.
  • Damage & Score Pipeline: Captures collisions with rocket rigidbodies, scoring, and triggering explosions.
  • Respawn Zoning: Destroys anchors, recalculates randomized positions in the player's vicinity, and re-anchors targets.
